================================
Installing pheweb python package
================================
Originally tried installing in python 3.11, but had
issues with some dependency called "greenlet"a

Using python 3.10.4 in a venv worked well:
* python -m venv .venv
* source .venv/bin/activate
* pip install -U pip
* pip install wheel
* pip install pheweb

This installed PheWeb version 1.3.16

Understanding how manhattan plots are made in pheweb 
====================================================
I was surprised that there were no python plotting libraries in the setup.py requirements section

Turns out that pheweb is using d3 to draw the manhattan and qq plots on the client side in javascript

When pheweb is loading/processing the data files it creates json files which can be used to make the
manhattan plots by d3 on the backend
